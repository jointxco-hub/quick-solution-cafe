# QS-08.5 — immediate secure-payment loader

The PayFast payment path is now accepted end-to-end. This is a UX polish phase.

## Why

Previously, after pressing **Pay securely with PayFast**, the customer could remain on the old
confirmation card for a moment while Quick Solution requested the signed PayFast URL.

QS-08.5 replaces that stale moment immediately with a full-screen transition:

- **Taking you to PayFast…**
- order number
- amount
- animated progress line
- "Your order is already saved"
- "Connecting securely. Please keep this window open."

If payment initialization fails, the loader automatically disappears because the existing payment
state changes to `error`, and the normal confirmation card returns with the error message.

## Apply

Copy this patch into the Quick-Solution-Cafe repository and run:

```powershell
node .\scripts\apply-qs085-payment-loader.mjs
npm run dev
```

## Acceptance

Create or use an unpaid order and press **Pay securely with PayFast**.

Expected:
1. the stale order page disappears immediately,
2. the secure-payment loader shows while the signed PayFast URL is being prepared,
3. browser navigates to PayFast in the same tab,
4. PayFast returns to the QS-08.4 payment confirmation page.
