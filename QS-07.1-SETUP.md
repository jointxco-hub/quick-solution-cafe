# QS-07.1 — Collection point visibility

This is the small follow-up to QS-07.

## Fixes

- Customer order confirmation now shows the exact selected collection point.
- Quick Point confirmations show the business name, area, collection fee, and Easy Locate link when available.
- Café collection confirmations show the exact café/branch.
- Delivery confirmations show the entered delivery address and that the fee is still pending confirmation.
- OPPS handoff preview now says the exact collection point instead of only `Collection`.
- OPPS handoff also shows the collection area when the immutable checkout snapshot contains it.
- The backend handoff mapper now carries the immutable `fulfilmentPointSnapshot` into OPPS source metadata.
- Existing stored handoff previews are backfilled from their checkout snapshot where possible.
