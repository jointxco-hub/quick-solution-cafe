# QS-03.1 — Secure files + live XOS Product Admin

Backend status: already applied to **Joint X XOS Staging**.

## What this patch changes

- Customer files are uploaded to the existing private `uploads` Supabase Storage bucket.
- Each uploaded file is tenant-prefixed and linked to the exact `commerce.service_order_items` row.
- Guest uploads use a short-lived opaque order upload token. The raw token is returned to the browser but only a SHA-256 hash is stored in the database.
- Maximum file size is 20MB. Accepted formats: PDF, DOCX, PNG, JPG/JPEG, WEBP.
- Product Admin now requires an authenticated XOS/OPPS staff account.
- Product Admin reads the live Quick Solution catalogue from Supabase and saves changes back to staging.
- Every admin save creates a new pricing version. Existing order pricing snapshots remain unchanged.

## Acceptance test

1. Open the storefront.
2. Choose **Print homework or notes**.
3. Select a small PDF/PNG/JPG/DOCX file.
4. Complete the guided order.
5. The completion screen should say that the file was uploaded securely.
6. Open `#admin`.
7. Sign in with an existing XOS/OPPS staff account.
8. Change one demo price by a small amount, save, confirm a new pricing version appears, then restore the price and save again if this is only a test.
