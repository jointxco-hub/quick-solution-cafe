# QS-08.2 hotfix

The Quick Solution payment intent function itself was valid, but the Edge Function was trying to call
the payment RPC through the `commerce` PostgREST schema. That schema is not exposed to the Edge
Function's API path in this project.

Staging is already fixed with service-role-only public bridge RPCs:

- `public.qs_begin_quick_solution_payment`
- `public.qs_get_quick_solution_payment_status`

and `quick-solution-payfast` is now version 4.

## What to do locally

Copy this patch into the repo. No UI code needs to change.

You can retry the same order `QS-260913-995E`; its payment token is still active.

After acceptance:

```powershell
git add .
git commit -m "QS-08.2 fix payment RPC bridge"
git push
```
