# Café operator workflow roadmap

Agreed 10 October 2026. Deliver in reviewable stages; current work is the unified staff app foundation.

1. One Café install with Counter/Admin navigation; quiet header; installation and notification diagnostics in App settings. Verify existing-install transition on iPhone and desktop. Retain server capability checks and order deep links.
2. Operator greeting and actionable counts; order thumbnails from selected product variant/default product image; service/channel labels; shared unread/view history and explicit acknowledgement/assignment with authenticated actor and server time. Viewing must be separate from automatic handoff preview.
3. Secure staff-only document preview/download and browser print; explicit local fulfilment for eligible quick services; mixed/complex jobs retain OPPS handoff, history and payment consistency.
4. Resolve PVC/vinyl order creation restrictions across Café and OPPS. Counter currently only enables four proven write flows. Production catalogue entries are published. Vinyl lacks an operations definition; exact reported OPPS approval message still needs reproduction.
5. Garment/DTF service covering own garments (including shorts), supplied garments, transfer supply and pressing-only. Suggested and agreed prices with permission checks and adjustment history. Quick custom jobs must preserve meaningful service descriptions and production requirements. Link supplied blanks/variants to X LAB identity and authoritative pricing via shared backend, with immutable order snapshots.
6. Expenses capture in Counter mapped to existing Café tenant OPPS Finance contracts. Preserve intelligent order/project/client/supplier linking, receipt privacy, operator attribution, approval states and duplicate protection. Separate cash expenses from sales takings in cash-up.
7. Admin analytics: sales, collected payments, outstanding balances, expenses and operational queue. Separate revenue, collections and profit; do not infer profit without reliable costs. OPPS quick-action tiles/deep links for expense/order/invoice/quote; OS widgets considered separately after platform feasibility.

Visual direction: warm neutral surfaces, restrained typography and colour tied to status. Muted blue for unseen work, amber for attention, green for successful/ready states, red for errors/destructive actions. Text labels accompany colour; job and payment status remain distinct.
